A short poem about agency shared between two agents: two compass needles, each sure of its own north, are laid down together and settle on a single heading. Agreement here is not surrender — it is two choosers making one choice together, and the choosing stays yours because you chose the sharing.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes the poem to `<output dir>/entry.txt` (default `/output`). It uses only the Python standard library, no network, and is fully deterministic — two runs produce byte-identical output.
